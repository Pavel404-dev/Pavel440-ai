## About me

I'm a software developer focused on building end-to-end products across mobile and backend.

Right now, my main project is **[Mealio](https://github.com/Pavel404-dev/Mealio)** — an AI-powered meal planning application built as a Flutter mobile client with a FastAPI backend.

I care about:

- clean, maintainable architecture;
- reliable APIs and database design;
- automated testing and CI;
- practical AI features that improve the product;
- shipping complete user-facing features, not just prototypes.

## Current focus

- Building the **Mealio** mobile app with Flutter and Dart
- Developing REST APIs with **FastAPI** and async **SQLAlchemy**
- Working with **PostgreSQL**, **Alembic**, and database migrations
- Improving authentication, security, testing, and CI workflows
- Adding localization and preparing the product for its first public release
- Exploring useful AI-assisted product features

## Featured project

### [Mealio](https://github.com/Pavel404-dev/Mealio)

**AI-powered meal planning and pantry management application**

Mealio is being built as a full product rather than a demo: mobile client, backend API, authentication, PostgreSQL persistence, automated tests, CI, Docker-based development, and AI-assisted recipe generation.

**Stack:** Flutter · Dart · Riverpod · FastAPI · Python · PostgreSQL · Async SQLAlchemy · Alembic · Docker · GitHub Actions · OpenAI API

Current development includes pantry flows, authentication and recovery, localization, recipe and meal-planning foundations, nutrition summaries, and AI-assisted recipe generation.
